43. tar - Archive Files

Scenario: Create a compressed tar archive of files and directories.
Basic Syntax:

tar [options] archive_name.tar files_to_archive

1. Create a Simple Archive (tar)

If you want to create an archive of files without compression, you can use the tar command as follows:
Command:

tar -cf archive_name.tar file1.txt file2.txt dir1

    -c: Create a new archive.
    -f: Specifies the filename of the archive.
    archive_name.tar: The name of the archive file you want to create.
    file1.txt file2.txt dir1: The files and directories you want to include in the archive.

Example:

tar -cf my_archive.tar file1.txt file2.txt /home/user/docs

    This creates an archive my_archive.tar that contains file1.txt, file2.txt, and the /home/user/docs directory.

2. Create a Compressed Archive with Gzip (tar.gz)

You can compress the archive using the gzip algorithm by adding the -z option.
Command:

tar -czf archive_name.tar.gz file1.txt file2.txt dir1

    -z: Compress the archive using gzip.
    archive_name.tar.gz: The name of the compressed archive file.

Example:

tar -czf my_archive.tar.gz file1.txt file2.txt /home/user/docs

    This creates a .tar.gz compressed archive.

3. Create a Compressed Archive with Bzip2 (tar.bz2)

If you want a higher compression ratio, you can use bzip2 by adding the -j option.
Command:

tar -cjf archive_name.tar.bz2 file1.txt file2.txt dir1

    -j: Compress the archive using bzip2.

Example:

tar -cjf my_archive.tar.bz2 file1.txt file2.txt /home/user/docs

    This creates a .tar.bz2 compressed archive.

4. Create a Compressed Archive with Xz (tar.xz)

For even better compression, you can use xz by adding the -J option.
Command:

tar -cJf archive_name.tar.xz file1.txt file2.txt dir1

    -J: Compress the archive using xz.

Example:

tar -cJf my_archive.tar.xz file1.txt file2.txt /home/user/docs

    This creates a .tar.xz compressed archive.

5. Create a Compressed Archive and Exclude Files

You can use the --exclude option to exclude files or directories from the archive.
Command:

tar --exclude='*.log' -czf archive_name.tar.gz file1.txt file2.txt /home/user/logs

    --exclude='*.log': Exclude all .log files from the archive.

Example:

tar --exclude='*.log' -czf my_archive.tar.gz file1.txt file2.txt /home/user/docs

    This creates a .tar.gz archive while excluding any .log files.

6. View the Contents of a .tar Archive

You can list the contents of a .tar archive without extracting it using the -t option.
Command:

tar -tf archive_name.tar

Example:

tar -tf my_archive.tar

    This lists all the files contained in the my_archive.tar archive.

7. Extract Files from a .tar Archive

To extract the contents of a .tar archive, you can use the -x option.
Command:

tar -xf archive_name.tar

Example:

tar -xf my_archive.tar

    This extracts the contents of my_archive.tar into the current directory.

8. Extract Files from a Compressed .tar.gz Archive

To extract the contents of a compressed .tar.gz archive, use the -z option with -x.
Command:

tar -xzf archive_name.tar.gz

Example:

tar -xzf my_archive.tar.gz

    This extracts the contents of my_archive.tar.gz.

9. Extract Files from a Compressed .tar.bz2 Archive

To extract a .tar.bz2 archive, use the -j option.
Command:

tar -xjf archive_name.tar.bz2

Example:

tar -xjf my_archive.tar.bz2

    This extracts the contents of my_archive.tar.bz2.

10. Extract Files from a Compressed .tar.xz Archive

To extract a .tar.xz archive, use the -J option.
Command:

tar -xJf archive_name.tar.xz

Example:

tar -xJf my_archive.tar.xz

    This extracts the contents of my_archive.tar.xz.

11. Extract Files to a Specific Directory

You can extract files to a specific directory using the -C option.
Command:

tar -xf archive_name.tar -C /path/to/destination

Example:

tar -xf my_archive.tar -C /home/user/extracted_files

    This extracts the contents of my_archive.tar into /home/user/extracted_files.
